MogTown · Instructor instructions

60-minute class

MogTown’s looks economy is booming, but profits are falling. Seven organizations hold different evidence. TrendTok is the shared news feed, not an eighth group.

End goal: Each group recommends a practical response, supports it with evidence, explains its trade-off, and updates it after the final reveal.

1. Set up and log in

Game website: https://hunternbh.github.io/mogtown-da-game/

  1. Divide the class into seven roughly equal groups. Give each group its matching two-page worksheet, one phone or computer, and a calculator.
  2. Open the game website. Choose the assigned organization and enter its code below. The group link preselects the organization; students still enter the code. Check all seven groups have opened Round 1.

2. Repeat the same cycle every round

In every round: read the released evidence; discuss and write the group answer; prepare the whole-class statement; each group shares for 30 seconds; release the next round. Use the worksheet's two boxes each time.

StageMin.Instructor action / round task
Setup5Allocate groups and materials; open the game using the matching code.
1 · Descriptive10What happened? Describe one or two changes and show one useful calculation. Do not claim causes yet.
2 · Diagnostic12Why might it happen? Give a likely explanation, supporting evidence, and one uncertainty.
3 · Predictive12What is likely next? Calculate the result of the released scenario and state the main assumption.
4 · Prescriptive12What should we do? Recommend an action with evidence, the main trade-off, and one KPI.
Final reveal9Release the final evidence after all Round 4 statements. Revise the same two Round 4 boxes; each group shares what changed and why.

Truth Rule: Teams may frame unlocked evidence, but must not invent data or contradict a metric. Answer direct questions about unlocked metrics truthfully.

Keep round and final release codes private until their scheduled stage. Collect worksheets and assess evidence, reasoning, assumptions, trade-offs, and willingness to update.
